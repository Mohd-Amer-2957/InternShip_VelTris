###### **File: 01\_App\_Basic.jsx**



This program defines a simple React functional component that displays a heading and an input box. It demonstrates how to handle user input using the **onChange** event to log values in the console. The **clicked**() function shows how events can be handled separately, though it’s unused. It also notes that the fragment tag <> must start right after return to avoid syntax issues.







###### **File: 02\_App\_Card.jsx**



This program builds a simple React app that imports and displays **multiple Card** **components** and one MyButton component. Each Card shows a greeting and a short paragraph, styled through CSS. The code demonstrates component reusability — rendering the same component multiple times within a parent container. It introduces the concept of modular UI design, where separate components handle individual parts of a page.







###### **File: `03\_App\_Props.jsx`**



This program demonstrates how to pass and use \*\***props**\*\* in React components. The main `App` component renders two `**Card**` components, each receiving different `**user**` and `**age**` values. Inside `Card`, these props are displayed with inline styling and logged to the console. It teaches dynamic rendering — how components become reusable and personalized through passed data.







###### **File: `04\_App\_CardList.jsx`**



This program dynamically generates multiple job cards using React’s **`map()`** method. The `App` component stores an array of company objects and passes each company’s details to the reusable `Card1` component. `**Card1` displays job information** like company **name, role, pay, and post count**, styled through CSS for a neat card layout. It demonstrates how to render lists, pass props efficiently, and build responsive UI components in React.
